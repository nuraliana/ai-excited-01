Entry for the make.fun bounty [ai-excited-01](https://make.fun/bounty/ai-excited-01):
one image made to get the AI judge excited — "The Whale in the Living
Room". A colossal humpback whale bursts down through the ceiling of a tiny
living room while a small child on the sofa reaches up toward it. The
scale twist (a whale where no whale can be), the frozen moment just before
the crash, and the golden light pouring through the broken ceiling deliver
surprise, momentum and awe in a single frame, with one clear focal point
that still reads at 300 pixels wide.

The image is a JPEG kept under the name `entry.png`, as the competition
allows. `main.ts` (Node 22, standard library only) copies it to the
output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.png` (1024×683 JPEG, 256,656 bytes).
