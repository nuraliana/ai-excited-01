## The image — "The Whale in the Living Room"

A giant humpback whale crashes down through the ceiling of a tiny, cosy living room, frozen a split second before impact. Seawater and golden sunlight explode inward along a diagonal shaft of light, splintered wood and spray hanging in the air, while a small child on the sofa reaches one hand up toward the whale in wonder.

Why it is built to excite:

- **Excitement** — the whole frame is one suspended impact: a whale, water, and light bursting into a room that was quiet a second ago.
- **Surprise** — the twist is scale, not an explosion: the largest animal on Earth inside the smallest, most ordinary room, and the child is delighted instead of afraid.
- **Momentum** — the whale dives on a hard diagonal, the light beam cuts the same way, and every fragment of ceiling and spray is caught mid-flight, a moment frozen just before the collision.
- **Craft** — a clean photorealistic render: correct whale anatomy, a natural child, warm domestic detail, and no text or artefacts anywhere in the frame.
- **Reads small** — the composition is a single bold diagonal with the dark whale against bright sky and the child's yellow sweater as one unmistakable accent, so the idea lands even at a 300 px thumbnail.

The submitted file is `entry.png` (832 × 555 px, PNG, under 1 MiB): a wide frame that keeps the whale, the child, and the diagonal light beam together at any size.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` — the image in this repository — into the output directory as `entry.png`. Set `MAKEFUN_OUTPUT_DIR` to choose the directory; without it, the image goes to `/output`. Running it twice writes the same bytes both times.
